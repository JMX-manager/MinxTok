# 素材与致谢

## 表情图片

界面里的情绪图标使用 Apple Color Emoji 的位图版本（`public/assets/emoji/*.png`、`public/assets/apple/*.png`），
版权归 Apple Inc. 所有，仅用于界面展示，不随本项目授权。

## 字体

界面字体优先使用系统字体：PingFang SC、-apple-system、HarmonyOS Sans SC、Noto Sans CJK SC。
数学排版使用系统自带的衬线字体（Times New Roman / Songti SC 等），未内嵌商业字体。

## 图标与线稿

化学实验装置图（试管、集气瓶、酒精灯、水槽等）为本项目手写 SVG，无外部素材依赖。

## 开源依赖

运行时零依赖。开发期只用到 `wrangler`（部署）与 Node 内置测试器。
