## 截图 01（2026-10-18 12:57）

**整体**：移动端深色主题，纯黑底，极简风，细分割线。

**结构（自上而下）**
1. 浏览器标题栏：`MinxTok · 明叙`，下方灰字为隧道域名（说明是网页/PWA 外壳）
2. 应用顶栏：左侧汉堡菜单（☰），中间标题 `MinxTok`，右侧「笑脸」与「搜索」两个图标
3. 对话流：
   - AI 消息：上方小字标签 `虾虾`，正文普通字重，无气泡框，靠分割线区分
   - 用户消息：小字 `我 · 01:29`（带时间），正文加粗，下方一个圆角小按钮 `引用`
4. 追问建议：AI 消息下方竖向排列三个圆角描边按钮（每次 3 条，即旧版「追问三连」的来源）
   - 数虾真有用吗，我咋越数越饿。
   - 除了数虾还能聊点啥催眠的。
   - 你困的时候一般听什么歌。
5. 额度提示：右下角灰字 `剩余 394 次`
6. 底部输入区：深灰输入框，占位文字 `和虾虾说点什么`，右侧浅色胶囊按钮 `发送`

**功能线索**
- 人设为「虾虾」，称呼用户「金明」
- 支持消息引用/回复
- 支持 AI 生成三条追问建议
- 有使用次数额度（剩余 N 次），推测按天或按总额计
- 有搜索与侧边抽屉（汉堡菜单）
- 内容偏口语、暖，带哄睡/陪伴语气
